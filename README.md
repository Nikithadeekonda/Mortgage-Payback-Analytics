# Mortgage-Payback-Analytics

## Project Overview
This project analyzes mortgage repayment behavior to understand borrower risk, predict default and early payoff behavior, and identify meaningful borrower segments.

The analysis uses mortgage records containing borrower, loan, credit, and economic information to support risk management, cash-flow planning, and loan pricing decisions.

## Technologies Used
- R
- RStudio
- Machine Learning
- Predictive Analytics
- Statistical Modeling
- ggplot2
- dplyr
- caret
- XGBoost

## Dataset
The dataset contains 622,489 records representing 50,000 U.S. mortgage borrowers observed across multiple time periods.

Key variables include:
- FICO Score
- Loan-to-Value (LTV) Ratio
- Loan Balance
- Interest Rate
- GDP Growth
- Unemployment Rate
- House Price Index
- Default and Payoff Status

## Project Workflow
1. Data understanding and quality assessment
2. Data cleaning and missing-value handling
3. Exploratory data analysis
4. Feature engineering
5. Data normalization
6. Principal Component Analysis (PCA)
7. Train-test partitioning
8. Classification modeling
9. Regression modeling
10. Borrower segmentation

## Models Used
- Decision Tree
- Logistic Regression
- Multiple Linear Regression
- XGBoost
- K-Means Clustering
- Hierarchical Clustering

## Business Applications
The analysis can support:
- Mortgage default risk identification
- Early payoff prediction
- Cash-flow planning
- Borrower risk segmentation
- Risk-based loan pricing
- Portfolio risk management
